# Statistical Tests

`two_sided_wilcoxon_summary.csv` is recomputed from the public per-page result
tables using `code/analysis/recompute_two_sided_wilcoxon_tables.py`.

Use this file for manuscript-facing paired Wilcoxon p-values. Other result JSON
files are retained for aggregate metrics and diagnostics; manuscript-facing
paired-test p-values are centralized here to avoid mixing older directional
diagnostics with the current two-sided tests.
